# 项目状态

核对日期：2026-10-15。本仓库整理自 ChatRoom 交付副本；核心业务文件与开发期原工程已核对一致。以下为代码审计与本地测试结论，硬件部署历史不作为本轮硬件验收结果。

## 已有主流程

- 注册、登录、错误提示；TCP 建连等待 5 秒，认证等待 10 秒。
- 在线用户列表、私聊、双方文本历史保存与读取。
- 登录后同步表情资源，向选定用户发送表情。
- 文件选择、8 MiB 附件限制、上传下载、按客户端指纹命中服务端缓存。
- 登录软键盘、中英界面、深浅主题、退出登录与退出程序。
- 退出程序时在 LVGL 释放前提交黑色空白帧。

## 未完成与边界

- UDP 没有完整发送链路；广播协议存在，但图形客户端没有广播发送入口。
- 设置分类标签及消息通知开关没有完整业务实现。
- 无群组、离线投递、消息撤回、可靠消息确认或自动重连闭环。
- 账户和会话数据使用文件存储；没有数据库、分页索引、配额、轮转和运维后台。
- 固定布局与设备节点面向当前 1024 × 600 板端，尚非通用硬件适配层。
- 源码包可以构建，尚无免配置 Windows 发行版或通用板端安装包。

## 已知问题

1. 密码以明文保存，通信没有 TLS；空账户配置会生成默认演示账户。
2. 服务端信任附件声明的 SHA-256，没有对上传内容重算核验。本轮隔离通信测试已复现声明值不符仍保存并转发。
3. 节点查找函数解锁后返回指针，断线线程可能释放节点，存在生命周期风险；需要并发专项检查。
4. 媒体发送持有全局 socket 写锁，慢客户端可能影响其他会话；尚未量化压力与吞吐。
5. 资源与运行数据依赖工作目录；触摸节点 `/dev/input/event6` 被写死。
6. 实际随附 LVGL 版本为 9.2.3 dev，SquareLine 导出注释为 LVGL 9.5，版本口径待统一。
7. Python 回归主要检查源码结构，不能替代真实 UI、硬件和长时间运行验证。

- 服务端辅助函数、协议解析、SHA-256、流式接收、上传通知、认证超时共 6 个 C 测试程序通过。
- 服务端编译、SDL2 客户端和 AArch64 客户端已有构建目录增量构建通过。
- 临时目录内的隔离服务端验证通过：注册、重复注册拒绝、认证、在线列表、私聊、历史记录、附件上传转发和缓存命中。
- 本轮未重新操作真实板端；触摸、LCD 黑屏、表情视觉与硬件长期运行仍待人工验收。

仓库整理后的可重复测试入口为 `sh tools/test.sh`；干净构建方式见根目录 README。当前仓库提供本地测试入口，尚未配置云端 CI。
